## 一、地方政府的资金来源

地方政府（以中国为例）的财力主要由四大块构成：

### 1. 一般公共预算收入（税收 + 非税）
- **税收**（核心）：
  - 增值税（与中央五五分成）
  - 企业所得税、个人所得税（与中央六四分成）
  - 地方独享税种：契税、土地增值税、城镇土地使用税、房产税、城市维护建设税等
- **非税收入**：行政事业性收费、罚没收入、国有资源（资产）有偿使用收入等。近年占比上升，部分反映土地财政下滑后的"补收"压力。

### 2. 政府性基金预算（关键是"土地财政"）
- 最重要的是**国有土地使用权出让收入**。
- 2021 年之前一度占地方综合财力的三到四成。
- 2021 年下半年房地产下行以来大幅萎缩，是当前地方财政最大的缺口来源。

### 3. 中央转移支付
- 一般性转移支付（税收返还、均衡性转移支付）+ 专项转移支付。
- 对中西部、财力薄弱地区极其重要，是维持"三保"（保基本民生、保工资、保运转）的关键。

### 4. 债务融资
- **地方政府专项债、一般债**：目前稳投资、补基建的主渠道之一。
- 过去大量依赖**城投平台**举债（隐性债务），当前处于化债、隐债显性化阶段。

### 当前趋势
- 土地财政退潮 → 对转移支付和债务依赖上升。
- 非税收入、盘活存量资产成为新增手段。
- 化债成为主线（2024 年大规模置换隐性债务）。
- 中长期方向：培育地方主体税种（房地产税、消费税后移划地方），但推进谨慎。

## 二、从土地财政到股权财政

**核心逻辑**：地方政府不再主要靠"卖地拿一次性现金流"，而是靠"持有资产/股权，获取长期、可持续的收益"。

从"卖地"到"持股"，本质上是从：
- **一次性收入**（土地出让，卖一块少一块）→ **可持续收入**（股权分红、增值、资本运作）
- **土地这一种资产** → **产业股权、国企资产、基金份额等多元资产**

政府角色从"土地一级开发商 + 出让方"，转向"**出资人 / LP / 战略投资者 / 国有资本运营者**"。

> 注意：股权财政目前还不是成熟、官方定义的制度，更像 2022 年后随土地财政退潮兴起的方向性探索。

## 三、股权财政的实现形式

### 1. 政府引导基金 / 产业投资基金
- 财政出资设母基金 → 子基金投向企业股权。
- 典型：**合肥模式**（投京东方、蔚来、长鑫存储）；深圳、苏州类似。
- 收益：股权增值 + 带动产业链形成的税收和就业。

### 2. 国有资本运营（做大做强国资）
- 通过国资委、国有资本运营公司（"两类公司"改革）持有并运营国企、上市公司股权。
- 收益：国有资本经营预算（国企上缴利润、分红）、资产证券化、混改增值。

### 3. 盘活存量资产
- 经营性资产（高速、管网、产业园、保障房）通过 **REITs、特许经营权转让、资产证券化** 变现，回笼资金再投资。

### 4. "以投带引" / 招商股权化
- 用股权投资替代税收返还、土地优惠来招商，财政补贴转为对企业的股权投资，共享企业成长收益。

## 四、土地财政 vs 股权财政对比

| 维度 | 土地财政 | 股权财政 |
|------|---------|---------|
| 资产 | 土地（不可再生、一次性） | 产业股权、国企资产（可持续、可增值） |
| 收入性质 | 一次性出让金 | 长期分红 + 资本增值 |
| 政府角色 | 出让方 | 出资人 / 投资人 |
| 风险 | 低（拿现金） | 高（投资可能亏损） |
| 对能力要求 | 低 | 高（专业投资能力） |

## 五、股权财政的现实挑战

1. **体量差太远**：土地财政巅峰全国一年 8 万亿+，股权回报是慢变量、体量小，短期难以填补缺口。
2. **风险高、周期长**：风投"投十个成一两个"，官员在"国有资产流失"问责压力下倾向保守。
3. **专业能力不足**：合肥模式难简单复制，背后有专业团队、产业判断力和运气。
4. **加剧地区分化**：产业和财力强的地区玩得转，弱势地区既没钱出资也招不到好项目。
5. **可能演变成变相举债**：明股实债、回购承诺，形成新的隐性债务风险。

### 中肯判断
- 股权财政是有价值的补充方向，但不足以完整替代土地财政。
- 更像收入多元化的"一条腿"，而非全部。
- 可持续方案仍要靠财税体制改革（地方税体系、央地关系、规范转移支付）。
- **股权财政 + 培育地方税种 + 规范举债** 三者结合更现实。

## 六、地方国资控股上市公司：概念与定位

### 专业名词
- 地方国资**"入主"/ "举牌" / "控股"上市公司**
- 学术/监管语境：**上市公司控制权转让 / 变更（收购控制权）**
- 媒体表述：**"国资入股潮"**

相关细分术语：

| 术语 | 含义 |
|------|------|
| **借壳 / 买壳上市** | 收购上市公司获得"壳资源"，把资产装入实现上市 |
| **壳资源** | 具备上市地位但主业较弱的上市公司本身 |
| **要约收购 / 协议转让 / 定向增发** | 取得控制权的三种主要交易方式 |
| **纾困（纾困基金 / 纾困入股）** | 民企遇困、大股东爆仓，国资出手接盘化解风险 |
| **资产重组 / 重大资产重组** | "重组后控股"通常伴随的资本运作 |

### 是否属于股权财政？——取决于动机

| 类型 | 动机 | 与股权财政关系 |
|------|------|--------------|
| **产业投资 / 平台运营型** | 持股获取分红与市值增值，借平台导入产业 | 最接近股权财政 |
| **纾困救助型** | 接盘爆仓民企，保就业保产业链 | 部分算，动机偏"稳定/救火" |
| **保壳 / 抢壳资源型** | 卡位稀缺上市地位，布局区域资本运作 | 股权财政的基础设施 |
| **国企改革 / 资产证券化型** | 国企资产注入、整体上市，提升流动性与估值 | 股权财政重要来源 |

### 现实争议
1. 控股上市公司不等于必然赚钱（尤其困境/ST 公司）。
2. 警惕明股实债与隐性风险。
3. "国进民退" vs "国有资产保值增值"的两难。
4. 收益最终通过**国有资本经营预算**入财政口径。

## 八、核心结论

- **地方财政**过去是"税收 + 土地出让 + 转移支付 + 城投举债"四条腿；如今土地这条腿明显变弱，重心向**中央转移支付、专项债/国债、盘活存量资产、非税收入**倾斜。
- **股权财政** = 政府从"卖地赚快钱"转向"持股赚长钱"，靠国有资本和产业投资的分红与增值获取可持续财力。方向正确，但受限于体量、风险承受机制和专业能力，短期更可能是补充角色，而非土地财政的"接班人"。
- **地方国资控股上市公司**专业上称"地方国资入主/收购上市公司控制权"（涉及借壳、壳资源、纾困等）；是否属于股权财政取决于动机——若为持股增值、产业运作、国有资本证券化，则是典型实践；若主要是纾困救火或战略卡位，则是相关但动机不同的行为。
