# 黄金阶梯式买入策略

## 原计划

900 以下阶梯式买入，每跌 10 元买入 1/15。也就是说最低到 750 的时候子弹刚好打完。

我们来计算一下原计划下每个价位的仓位比：

| 价格 | 累计仓位 | 占比 |
| :--- | :---: | ---: |
| 890 元 | 1/15 | 6.6% |
| 880 元 | 2/15 | 13.3% |
| 870 元 | 3/15 | 20% |
| 860 元 | 4/15 | 26.6% |
| 850 元 | 5/15 | 33.3% |
| 840 元 | 6/15 | 40% |
| 830 元 | 7/15 | 46.6% |
| 820 元 | 8/15 | 53.3% |
| 810 元 | 9/15 | 60% |
| 800 元 | 10/15 | 66.6% |
| 790 元 | 11/15 | 73.3% |
| **790 元是安全边际线（70%）** | | |
| 780 元 | 12/15 | 80% |
| 770 元 | 13/15 | 86.6% |
| 760 元 | 14/15 | 93.3% |
| 750 元 | 15/15 | 100% |

## 1. 为什么 790 是安全边际线（也就是 70% 的边际线）？

750 是在想到的所有重大利空落地后对于价格的影响，也就是最坏情况。假设最终最低点真的是 750：

- 如果 790 已经 100% 仓位：平均成本约 820 元左右。
- 如果 790 只有 73% 仓位，最后一路补到 750：最终平均成本会降到 790 附近。

两者相差接近 30 元。对于黄金这种资产来说，30 元的成本差距已经非常明显。

## 2. 为什么边际线不是 50%？

如果 790 只有 50% 仓位，意味着真正跌到 750 以后，还有 50% 的资金没有投入。这种策略虽然风险最低，但是上涨以后容易踏空。

例如：790 直接反弹到 950，你实际上只有一半仓位赚钱，收益率明显下降。

> **前 70% 是生命线，后 30% 是缓冲线，负责缓冲利空带来的风险。**

## 调整后的策略

现在黄金的利空因素出得差不多了，我们需要给它重新估值。在当前的情况下，我给他的最低价值是 800 元（这里面包含了突发的黑天鹅等利空因素的影响）。

对应的策略上需要调整，只不过还是坚持 70% 的安全边际线，每跌 10 元买入的原则。调整后的策略是 (900 - 800) / 10 = 10：

| 880 元 | 2/10 | 20% |

| **830 元是安全边际线（70%）** | | |
| 830 元 | 7/10 | 70% |
| 820 元 | 8/10 | 80% |
| 810 元 | 9/10 | 90% |
| 800 元 | 10/10 | 100% |

只需要按照现在的黄金价格和上面的表格去对应调整仓位就行。
