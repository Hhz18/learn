> 土地承包方：**海南省农垦投资控股集团有限公司**（控股股东）
> 数据整理日期：2026-07-24

## 一、土地承包关系背景

农垦集团下属分支机构、附属企业合法取得的国有划拨土地使用权，统一授权给农垦集团处置；农垦集团将其及授权范围内的土地使用权**承包给海南橡胶使用**，主要用于种植橡胶林、防护林等林木以及从事其他农业生产活动。

### 1.1 三类土地与年承包金（2010 协议初始定价）

| 土地类型 | 年承包金 | 备注 |
| -------- | -------- | ---- |
| **开割胶园 一级** | **85 元/亩/年** | 最优土地 |
| **开割胶园 二级** | **70 元/亩/年** | 中等 |
| **开割胶园 三级** | **60 元/亩/年** | 较差 |
| **未开割胶园** | **40 元/亩/年** | 幼龄胶园 |
| **防护林** | **30 元/亩/年** | 生态用地 |

> 每三年参照届时的社会物价水平、通货膨胀及海南省同类农业用地的使用权价值等因素的变动幅度，如三年内上述任何一项因素变动幅度**超过 20%**，则由双方另行协商确定年承包金的调整幅度。

### 1.2 2010 协议关键节点

**2010 年 9 月**，根据农垦集团国有土地确权、办证的进展及公司承包使用有关国有土地情况，农垦集团与公司签署《土地使用权承包协议之补充协议》：

- 重新确认承包土地总面积：**351.55 万亩**
- 原定价原则不变
- 土地承包金总金额确定为：**21,470.51 万元/年**
- 加权平均单价：约 **61.07 元/亩/年**
- 补充协议自签订次月起执行

## 三、关键观察与结论

### 3.1 总体趋势

**从 2010 协议金额 21,470.51 万元 → 2025 年 19,716.68 万元，累计下降约 8.17%**

- **2010—2022**：协议金额固定，但公司未在年报中**单独披露**土地承包费（合并入"营业成本 / 管理费用"中的"土地使用权摊销"或"土地租金"等子科目，需逐年翻阅附注）
- **2023 起**：年报开始单独披露
- **2023 → 2024**：保持 19,745.05 万元**不变**
- **2024 → 2025**：微降 28.37 万元（-0.14%）

### 3.2 下降原因分析

| 因素 | 影响方向 | 说明 |
| ---- | -------- | ---- |
| **辅业剥离 / 农场公司剥离** | 减少土地面积 | 2017—2018 期间公司剥离多个农场辅业，承包土地总面积下降 |
| **协议未调整单价** | 持平 | 协议每三年一调，但 2010 协议以来**未触发 20% 调整阈值** |
| **土地等级结构变化** | 略微下降 | 部分开割胶园转为防护林或未开割胶园，单价降低 |
| **2025 微降** | 小幅调整 | 可能是边界调整或等级微调 |

### 3.3 占收入比变化（按已知数据测算）

| 年度 | 营业收入（亿元） | 土地承包费（亿元） | 占收入比 |
| ---- | ---------------- | ------------------ | -------- |
| 2010（协议年） | 63.42 | 2.1471 | **3.39%** |
| 2023 | 376.87 | 1.9745 | **0.52%** |
| 2024 | 496.73 | 1.9745 | **0.40%** |
| 2025 | 422.37（前三季/年化估） | 1.9717 | **0.47%** |

> **结构性结论：** 海南橡胶作为典型**资源型农业企业**，土地承包费是其最稳定的**刚性支出**之一（与橡胶树生命周期、种植面积强绑定，不随短期价格波动）。但随着公司**贸易业务规模化**（2018 后贸易/加工业务收入大幅扩张），土地承包费**占收入比已从 3.39% 降至 0.40%—0.52%**——这是一项**比利润更稳定的"地基"**。
