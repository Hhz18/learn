## 四、利率结构分析

### 4.1 存款利率 vs 贷款利率利差

| 项目 | 下限 | 上限 | 利差 |
| ---- | ---- | ---- | ---- |
| 存款利率 | 0.3% | 2.5% | — |
| 贷款利率 | 2.3% | 2.9% | — |
| **利差区间** | **1.8%** | **0.4%** | — |

**观察：**

- 利差区间差异巨大——下限 1.8%、上限仅 0.4%
- 利差结构反映**存款定价偏高、贷款定价偏低**，对上市公司而言**净息差收益**
- 与同期商业银行对公存款（一般 0.2%—1.8%）和贷款（一般 3.0%—4.5%）相比，**存贷款利差相对市场化**

### 4.2 与同期市场利率对比（参考）

| 类型 | 海南橡胶在海垦财务公司 | 商业银行同期参考 | 对比 |
| ---- | ---------------------- | ---------------- | ---- |
| 活期/定期存款 | 0.3%—2.5% | 0.2%—1.8% | **公司略高** |
| 短期/长期贷款 | 2.3%—2.9% | 3.0%—4.5% | **公司略低** |

**解读：** 通过集团财务公司融资的**综合成本低于市场**，是关联交易的实际利益输送。

## 七、关键观察与风险信号

### 7.1 集中度风险（★★★★★ 极高）

| 风险 | 说明 |
| ---- | ---- |
| **交易对手单一** | 全部存贷款仅在海垦财务公司一家 |
| **账期错配风险** | 存款利率 ≤ 2.5%、贷款利率 ≥ 2.3%，净息差对集团财务公司不利，可能引发财务公司流动性紧张 |
| **担保链传导** | 集团（海垦控股）→ 财务公司（80%）→ 上市公司（存款 30 亿级），构成三层传导链 |

### 7.2 关联交易定价合理性（★★★★ 高）

- 存款利率上限 2.5% 略高于商业银行（一般 1.8%），对上市公司**有利**
- 贷款利率下限 2.3% 略低于商业银行（一般 3.0%），对上市公司**有利**
- **但综合利差收益属于关联交易的利益输送**，需关注是否触发交易所合规审查

### 7.3 内部利益冲突（★★★ 中—高）

- 海南橡胶**自身持有海垦财务公司 20% 股权**（1 亿元出资）
- 作为股东，公司可从财务公司利润中分红
- 作为存款方，公司获取利息收入
- 作为贷款方，公司支付利息
- **三方利益互相交织，独立审计难度大**

### 7.4 2024 年报披露的 4.56 亿元贷款余额

- 仅占 60 亿额度的 **7.6%**，**授信空间极大但使用率低**
- 反映公司**对集团财务公司依赖但未充分利用**——更可能用于**风险缓冲**而非日常融资

### 7.5 集团流动性传导信号

- 2025-11：海垦控股拟发行 **21 亿元可交换债**（以海南橡胶股票为标的）
- 集团层面融资需求上行 → **财务公司流动性管理压力同步上行**
- 一旦财务公司出现兑付问题 → **上市公司 29.56 亿存款安全受威胁**

## 八、综合判断

### 8.1 资金安全等级

| 维度 | 评估 |
| ---- | ---- |
| **存款本金安全** | 中—高（集团国企背景，但单一对手方风险显著） |
| **存款收益** | 略高于市场（关联交易利益输送） |
| **贷款成本** | 略低于市场（关联交易利益输送） |
| **综合关联交易价值** | **正向**（净利息节余 + 存款利息增厚） |
| **但代价** | 资金安全**完全依赖集团信用** |

### 8.2 一句话结论

> 海南橡胶近 **30 亿元货币资金几乎全部沉淀在单一关联方**（海垦财务公司），2024 年金融服务协议限额翻倍至 **60 亿授信 + 40 亿存款**，实质上将上市公司的**流动性完全绑定在控股股东体系内**——短期享受低融资成本与高存款利息的关联交易红利，长期承担**集团信用传导风险**与**治理透明度折损**。
