# 2011–2026 国内天然橡胶行业：倒闭潮与存活企业调研（初稿）

> **状态**：深度研究工作流进行中（已完成：范围分解 + 5路并行搜索 + 部分抓取验证）。本文档为**阶段性整理**，待对抗验证与综合阶段完成后将更新补充。
>
> **检索范围**：2011年（胶价见顶）至 2026 年（当前），覆盖种植、加工、流通三类企业。

---

## 一、行业大背景：15 年长周期下行的"出清曲线"

| 时间节点 | 事件 | 数据 |
|---|---|---|
| 2011 年 | 沪胶主力突破 4 万元/吨创历史新高 | 牛市顶峰 |
| 2014 年 | 胶价腰斩；中国进口天然橡胶 210.77 万吨（1–10 月） | 国内 80% 需求依赖进口 |
| 2017–2019 年 | "自 2011 年以来长达 8 年的低迷"；民营加工厂大面积亏损、停产 | 行业整合迫在眉睫 |
| 2018 年 | 国内全乳胶年均价 1.1 万元/吨 | 仅为 2011 年最高价的约 35% |
| 2019 年 | 胶价跌至万元/吨水平 | 较 2011 年高点跌近 70% |
| 2020–2022 年 | 新冠疫情冲击；2022 年前三季度海胶净亏损 1.32 亿元，同比下降 107% | 二次出清 |
| 2024–2026 年 | 行业整合加速；央地协同打造"中国神胶" | 头部集中度大幅提升 |

- 国内自给率仅约 15%，主产区集中在云南、海南、广东。
- 2014 年起云南、海南民营胶林出现大面积"弃割"，胶工流失，民营收购点关门。

## 二、倒闭 / 退出企业（按时间顺序）

### 2.1 民营加工、种植端（2014–2020 第一轮出清）

- **云南 / 海南民营胶林**：2014 年起大面积弃割、弃管，部分胶树仅种植 10 年即被提前割胶（正常周期 30 年），反映上游种植端最先出清。
- **一年半间 27 家橡胶企业破产**（再生胶网统计，2018–2019 年间）：直接量化第一轮民营出清浪潮。
- **海南民营收购点**：2015–2017 年陆续关闭。

### 2.2 国资背景的合成 / 氯丁橡胶（2024–2026 第二轮出清）

| 企业 | 时间 | 事件 |
|---|---|---|
| **山西合成橡胶集团** | 2024-12-11 受理破产 → 2025-03 与职工解除合同 → 2025-04 拍卖 238 项债权（起拍价 3229.34 万元） | 始建 1965 年，曾是中国最大氯丁橡胶生产基地，隶属中国中化 |
| **东营曼迪橡胶科技** | 2025-02 破产拍卖 | 山东民企 |
| **江阴安基橡胶** | 2024-11 重整，起拍价 9000 万元 | 江苏 |
| **迪马橡胶** | 2024-11 资产重整拍卖流拍 | |
| **云南红河浩志橡胶** | 2024-10 启动降价拍卖（土地/厂房 3536.43 万元、设备 706.25 万元） | 主营"澜沧江"橡胶输送带，成立于 2012 年 |
| **东营昊正橡胶** | 2026-03 山东省广饶县法院受理破产清算（(2026)鲁0523破2号） | 因经营不善、资不抵债，最新一批中小橡胶企业退出 |

> **注意**：云南红河浩志橡胶主营橡胶输送带（下游制品），并不直接属于天然橡胶上游种植 / 初加工；列入此处用以说明橡胶产业链整体困境。

## 三、存活下来的企业（按梯队）

### 3.1 第一梯队：央企 + 地方国企巨头（行业整合主导方）

| 企业 | 性质 | 当前定位 |
|---|---|---|
| **海南橡胶（601118.SH）** | 海南省农垦集团控股 + 海垦控股集团 | 中国资本市场**唯一**的天然橡胶全产业链上市公司；国内种植面积占全国近 30%；2021 年营收超 153 亿元；2023 年起明确为"全球天然橡胶产业龙头" |
| **云南农垦集团** | 云南省国资委 | 西南种植、加工主力 |
| **广东广垦橡胶集团** | 广东省农垦集团 | 华南种植、加工主力 |
| **中化国际（600500.SH）** | 中国中化控股 | **2022 年剥离天然橡胶业务**，转型精细化工（环氧树脂、聚合物添加剂、芳纶、ABS、尼龙 66） |

### 3.2 第二梯队：被并购 / 整合方

| 企业 | 状态 |
|---|---|
| **合盛农业（Halcyon Agri，HAC）** | 2022-11 海南橡胶以 1.81 亿美元收购其 36% 股份；2023-02 完成交割，海胶成为间接控股股东（持股 36%–70.8%）。HAC 全球拥有 4 处种植园、37 家工厂、产能约 142.9 万吨 |

### 3.3 第三梯队：区域国企 + 民营种植园（依赖政策生存）

- 海南省国营红华农场等国有农场系统——通过价格（收入）保险等政策性补贴维持。
- 部分云南、广东民营加工厂通过承接代工、定制化产品存活。

## 四、产业整合：央地协同打造"中国神胶"

- **2022-11**：中化国际剥离橡胶资产；海南橡胶斥资近 2 亿美元现金收购合盛农业，启动强制要约。
- **2023-02**：海南橡胶正式控股合盛农业（HAC）。
- **国务院国资委发文**：明确"加强央地协同，海南橡胶与中化国际共同打造世界一流天然橡胶全产业链科技集团"。
- 战略意图：通过整合形成"中国神胶"，对标国际四大橡胶巨头。

---

## 五、政策托底：天然橡胶价格（收入）保险

- **2017 年**：价格（收入）保险试点启动。
- **2018–2019 年**：海南全省覆盖。
- **2024 年**：海南橡胶触发胶价波动保险赔付 653.06 万元（计入"其他收益"）。
- **2019–2024 年（稳产行动）**：海胶与上期所合作累计提供支持资金 5565.1 万元，受益胶农 11.1 万人次，挂钩现货产量 16.5 万吨，赔付 5218.7 万元。

## 六、初步结论（待验证后修订）

1. **出清轨迹**：2014–2020 年民营种植 / 加工端第一轮出清（27 家+）→ 2024–2026 年国资背景合成橡胶 / 制品端第二轮出清（山西合成橡胶等）。
2. **存活模式**：
   - **龙头化**：海南橡胶通过并购 HAC、做强"中国神胶"。
   - **退出转型**：中化国际剥离橡胶业务，聚焦精细化工。
   - **政策依赖**：区域国企与民营靠价格保险稳产行动存活。
3. **风险点**：极端天气、期货套保损失、产能持续过剩（2011 年扩张的胶树仍在旺产期）。
