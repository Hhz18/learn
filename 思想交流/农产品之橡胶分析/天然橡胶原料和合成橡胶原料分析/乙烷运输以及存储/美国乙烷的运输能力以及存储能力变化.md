美国乙烷贸易运输能力与存储能力分析
==========================================

研究范围：美国乙烷出口侧的运输能力（含海运VLEC船队、出口终端、配套低温储罐、内陆集输管道）及近三年（2023–2025）变化趋势。

一、总体结论
------------

> **核心关键：和23年相比，25年订单数量翻了一倍，在役船舶增加速度低于订单增长速度，美国墨西哥湾出口终端及低温储罐持续扩建。**

- **运力侧**：2023–2025年VLEC船队规模从约24艘扩至约30艘，但订单已达58艘VLEC + 8艘ULEC，在役增速远低于订单增速，2026–2028年是集中交付高峰。
- **出口能力侧**：美国乙烷出口能力从2023年约45万桶/日提升至2025年超60万桶/日，EIA预计2025年同比+14%，2026年继续+16%。
- **储罐侧**：以新建出口终端配套的超大型双层绝热低温罐为主，单罐容量普遍达数万立方米级；Neches River一期配套5万吨储罐。
- **管道侧**：ATEX Express（约19万桶/日）打通阿巴拉契亚→墨西哥湾东向集输；Mariner East系列支撑Marcus Hook终端向欧洲分流。
- **结构性矛盾**：美国出口能力短期内难以满足中国快速增长的市场需求，码头扩建周期长达5–6年。

二、美国乙烷出口能力变化（2023–2025）
-------------------------------------

| 年份 | 美国乙烷出口能力（约） | 主要变化 |
| :--- | :--- | :--- |
| 2023 | 约45万桶/日 | Morgan's Point、Nederland为主 |
| 2024 | 约49万桶/日（实际出口创纪录） | 中国需求快速增长 |
| 2025 | 超60万桶/日（新增终端投运） | Neches River一期投产，Nederland扩容 |

EIA预测：

- **美国乙烷日产量**（2025年预测）：约 **280万桶/日**，占全球总产量约 **65%**。
- **2025年美国过剩出口产能**（2025年4月）：约 **55万桶/日**。
- **2026年出口量增长**：继续约 **16%** 增长。
- **2025年中国乙烷进口预测**：约 **630万吨–820万吨**（同比+9%~34%）。

> 注：美国出口能力的扩张主要受新增出口终端和更大船型投入使用推动，但终端建设周期长，运力释放滞后于订单。

三、VLEC运输船队规模与结构
------------------------

VLEC（Very Large Ethane Carrier）是美国出口乙烷的主力船型，单船货舱容积85,000–99,000 m³，可装乙烷约80–100万桶，航速16–18节，单艘造价1.6–1.7亿美元，建造周期约3年。

船队规模变化

| 年份 | 全球运营VLEC（约） | 新船订单（累计） | 供需状态 |
| :--- | :--- | :--- | :--- |
| 2023 | 约24艘 | 约30艘 | 供不应求 |
| 2024 | 约27–29艘 | 40余艘 | 中国企业大量租船/订船 |
| 2025 | 约30艘 | 58艘VLEC + 8艘ULEC在建 | 运力进入快速扩张期 |

> 注：在役船舶增速低于订单增速，因VLEC从下单到交付通常需要约3年，因此**2026–2028年是集中交付高峰**。

中国买方船队（直接影响美国海运能力锁定）

| 公司 | 现有VLEC | 在建/已订 | 运力规模 |
| :--- | :--- | :--- | :--- |
| 卫星化学 | 14艘 | 6艘（2023.7下单，2026年初交付） | 现役137.2万m³ + 在建59.4万m³ |
| 万华化学 | 0艘（自有） | 11艘已订 + 9艘AW Shipping合资99000m³（2025–2027交付） | 已订109.4万m³ + 合资约89.1万m³ |
| 太平洋气体船 | — | 与万华化学签VLEC长期租约 | 9.9万m³级新船在建 |

> 注：2024–2027年间，VLEC船运输的乙烷主要流向**卫星石化**和**万华化学**两家炼厂。卫星方面一二期合计250万吨乙烷制产能，后续合计约380万吨；万华规划285万吨，合计约380万吨乙烷制产能。

新船建造动态（2024–2025）

- **江南造船交付**（2024.04）：99,000 m³ VLEC "GAS CHANGJIANG"号，总长230米，型宽36.6米，自主研发B型舱围护系统，入级美国船级社。
- **三星重工**（2025.01）：法国GTT获3艘100,000 m³ VLEC Mark III薄膜围护系统订单，总价约5亿美元。
- **山东海洋集团/江南造船**（2025.08）：9.9万m³ VLEC（H2822船）开工，太平洋气体船与万华化学长租项目。
- **8艘ULEC**：150,000 m³级超大型乙烷船在建，远超常规VLEC规模。

五、低温乙烷储罐设施
-------------------

乙烷储存需在 **-104℃** 超低温环境或高压条件下进行，储存成本极高。

美国侧储罐

- 美国企业通常不会单独公布乙烷储罐总容积，但公开资料显示：近三年的投资重点是新增出口终端配套的大型低温储罐。
- 新建项目普遍配套超大型双层绝热低温储罐，单罐容量通常达到数万立方米级，并通过多罐配置满足连续装船需求。
- 储罐建设与码头、装船臂、制冷系统同步扩建，以适配VLEC装船节奏。
- Enterprise Neches River一期配套 **5万吨** 储罐（2025年建成）。

中国侧配套储罐（与美方对接）

- **万华化学烟台2台16万m³低温乙烷罐**（2025.04投运）：中国化学华陆公司EPC总承包，刷新同类超大型低温罐工期纪录；单罐内壁直径82米，拱顶重657.73吨，抬升高度36.86米。
- 该项目位于山东省烟台市万华工业园区西港，建设两座16万m³的全包容低温罐组，采用企业自有专利技术。
- 中国侧储罐能力是承接美方长航线VLEC到岸的关键缓冲，决定了美方船队的周转效率。

> 注：储罐投资周期长（约2–3年），是美方出口扩张之外、中方接货能力的"第二瓶颈"。

六、内陆集输管道
---------------

美国乙烷出口需先将内陆产区（NGL分馏后）的乙烷通过管道集输至墨西哥湾或Marcus Hook出口终端，主要管道系统：

ATEX Express（Enterprise运营）

| 项目 | 数据 |
| :--- | :--- |
| 起讫 | 阿巴拉契亚（PA/WV/OH）→ 墨西哥湾（Texas） |
| 乙烷输送能力 | 约19万桶/日 |
| 介质 | 乙烷 + 丙烷 |
| 战略意义 | 打通页岩气内陆产区→出口终端的东向集输通道 |

Mariner East系列（Sunoco/Energy Transfer运营）

| 项目 | 数据 |
| :--- | :--- |
| 路径 | Marcellus/Utica页岩区 → Marcus Hook（宾州Delaware River） |
| 线数 | Mariner East 1、2、2X三条 |
| 介质 | NGL（乙烷、丙烷、丁烷） |
| 能力 | 综合NGL能力数十万桶/日（其中乙烷部分未单独披露） |
| 战略意义 | 服务Marcus Hook终端，绕开墨西哥湾瓶颈分流欧洲市场 |

其他配套管道

- Texas州内由Enterprise、Energy Transfer等运营的NGL管道网络，将Mont Belvieu等分馏中心与Morgan's Point、Nederland、Neches River等终端相连。
- 墨西哥湾内短距转运管道、装船臂配套由各终端自建。

> 管道能力整体富余，但与出口终端、VLEC船位之间存在"木桶短板"——任何环节受限都会影响最终出口能力。

八、核心判断
------------

1. **船队扩张是中长期主线**：2025年订单已超在役船数近一倍，2026–2028年集中交付将彻底改变海运能力格局。
2. **终端是短期最大瓶颈**：墨西哥湾码头扩建需5–6年，2025–2027年难以快速新增大型出口能力，已建终端的装船速度（4.5万桶/小时级）是实际节奏上限。
3. **储罐能力同步吃紧**：美国侧出口端储罐 + 中国侧接货端储罐（如万华烟台2×16万m³）都在抢建，但超低温储罐投资周期长，构成"第二瓶颈"。
4. **管道侧相对富余**：ATEX、Mariner East已建立内陆产区→出口终端的干线通道，集输能力基本满足需求。
5. **买方（卫星、万华）锁定运力**：中国两大乙烷制产能主体通过自有船队 + 长租 + 合资船队（AW Shipping、太平洋气体船）锁定了未来3年大部分新增运力，对美方议价权上升。
6. **欧洲分流形成地理套利**：Marcus Hook约7万桶/日的对欧出口接近满负荷，是墨西哥湾瓶颈之外的有限替代通道。
