# 以股入道

---

## 壹· 吾观股市如观世间万象

**股市者，众生之相也。**

余尝观股市之内，千股竞逐，涨落无常，诚如世间万象：

今日之朝阳，明日或为夕阳；今朝之默默无闻，转瞬即成万众追捧。此天道循环，周而复始，亘古如斯。

余见世人趋之若鹜，犹股民之追涨杀跌；世人避之不及，犹股民之恐慌抛售。究其本源，皆因贪嗔痴慢疑五毒未除，不得解脱。

- 世人争逐高薪之业，恰如股民追捧高位之股，殊不知物极必反，盛极必衰，诚可叹也。
- 人生之起伏，何异于K线之波动？起落之间，自有定数。

余以为，人生于世，有起有落，犹K线之上下，如波浪之起伏。君子处逆境而不馁，待时机而后动，此乃大智之举也。

## 贰· 命运之辨：点线之理

**命者，时也；运者，势也。**

### 命：一瞬之变，机缘之至，随机之数

命者，如K线之突变也，或一日暴涨，如平步青云，一朝得志；或一日暴跌，如大厦将倾，一落千丈。此乃"命"，乃机缘之至，不可强求，亦不可预料。

古云："一命二运三风水，四积阴德五读书。"

命者，天也，运者，时也。

### 运：长久之势，趋势之行，周期之律

运者，犹如大盘之走势也，或十年上升，如御风而行，顺势而上；或十年下行，如逆水行舟，步步维艰。此乃"运"，乃大势所趋，可察而不可逆。

《道德经》有云："道可道，非常道。"

运者，道之显也，趋势之谓也。

### 命与运：点线相成，共构人生

```text
命（点）+ 运（线）= 人生（轨迹）
├─ 命：关键时刻的转折
├─ 运：长期发展的趋势
└─ 人生：命与运交织而成
```

犹：

```text
├─ K线（点）+ 趋势（线）= 股市（走势）
├─ 突变（点）+ 惯性（线）= 命运（轨迹）
└─ 时机（点）+ 选择（线）= 成败（结果）
```

## 叁· 趋势之道：不争之争

圣人之道，为而不争；众人之道，争先恐后，趋之若鹜。

世人争热门，争高薪之位，如追高位之股；逐热门之业，如随炒作之风，抢风口之势，如赶泡沫之潮。

然则"日中则移，月满则亏"，热门之极，即是衰退之始。

人应当顺势而为，皆为趋势。"人弃我取，人取我与。"

## 肆· 周期之律：盛衰之理

**阴阳转化，周而复始。**

### 万物皆周期

《易经》之理：

```text
太极生两仪 → 阴阳相生 → 消长转化 → 循环往复
```

股市之理：

```text
繁荣 → 过热 → 衰退 → 萧条 → 复苏 → 繁荣
```

人生之理：

```text
得意 → 躁动 → 失意 → 沉淀 → 顿悟 → 得意
```

行业之理：

```text
萌芽 → 成长 → 繁荣 → 成熟 → 衰退 → 萌芽
```

### 知周期者，知进退

- **知盛衰**：盛极而衰，衰极而盛
- **知进退**：进退有度，不失其时
- **知取舍**：取舍有据，不随风动

《史记·货殖列传》云：

> "旱则资舟，水则资车，物之理也。"

（天旱时投资船只，发水时投资车辆，此乃万物之理）

## 伍· 处逆之道：屈身待时

**君子藏器于身，待时而动。**

### 屈身守份，非无能也

"屈身守份以待天时"，此非无能，乃大智也：

**屈身者，非屈服也**

- 如龙之潜渊，非无力也，待时也
- 如凤之栖梧，非无能也，择木也

**守份者，非安分也**

- 守其本份，积其底蕴，厚积薄发
- 守其初心，修其内功，待机而动

**待时者，非无为也**

- 观察趋势，研究时机，蓄势待发
- 学习精进，积累资源，待风而起

### 古人之训



> "君子藏器于身，待时而动，何不利之有？" -《周易·系辞下》

> "曲则全，枉则直，洼则盈。" -《老子》

> "虽有智慧，不如乘势；虽有镃基，不如待时。"-《孟子》
