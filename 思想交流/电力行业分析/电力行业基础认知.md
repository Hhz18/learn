# 电力行业基础认知

> 本文档梳理电力行业的基础知识框架，作为后续研究和分析的认知底座。

---

## 一、行业本质

电力行业是**能源转换与公用事业**的结合体，具有以下底层属性：

- **二次能源**：电力由一次能源（火电、风光水核等）转换而来，本身难以大规模储存
- **公用事业属性**：关系国计民生，受政府严格监管，价格非完全市场化
- **瞬时平衡**：发电与用电必须实时平衡（秒级），无法像普通商品那样提前生产库存
- **自然垄断环节**：输电、配电具有网络效应和规模经济，历史上由国有资本主导
- **资本密集型**：单个项目动辄数十亿至上千亿投资，回收周期长（10-30年）

---

## 二、产业链结构

电力行业按业务流程可分为四大环节：

| 环节 | 含义 | 主要特征 |
|------|------|----------|
| **发电** | 将一次能源转换为电能 | 多种技术路线、竞争性较强 |
| **输电** | 高压远距离输送 | 自然垄断、电网公司主导 |
| **配电** | 中低压分配到用户 | 自然垄断、地方属性强 |
| **售电** | 向终端用户销售 | 部分市场化（工商业）、部分管制（居民农业） |

> 关键概念：**厂网分开**（发电与电网分离）是2002年电力体制改革的核心动作之一。

## 三、发电方式分类

### 3.1 按能源类型

**传统能源**
- **火电**：包括燃煤、燃气、燃油，以煤电为主。出力稳定、可调度，是电力系统的"压舱石"。
- **水电**：利用水力发电，包括常规水电和抽水蓄能。具有调峰、调频、黑启动等多重价值。

**新能源/清洁能源**
- **风电**：分陆上风电和海上风电，具有随机性、波动性。
- **光伏（太阳能发电）**：分集中式和分布式，午间出力高，夜间为零。
- **核电**：出力稳定，基荷电源，但建设周期长、安全要求高。

**其他形式**
- 生物质发电、地热发电、潮汐能等（占比小）

### 3.2 按电力系统作用

- **基荷电源**：长期稳定运行（火电、核电、径流水电）
- **调峰电源**：可灵活调整出力（燃气、抽水蓄能、储能）
- **间歇性/波动性电源**：风光发电，需要配合调节资源

### 3.3 关键特征对比

| 类型 | 出力稳定性 | 调节能力 | 建设周期 | 度电成本趋势 |
|------|-----------|---------|---------|-------------|
| 煤电 | 高 | 中 | 2-3年 | 略升 |
| 燃气 | 高 | 高 | 1-2年 | 随气价波动 |
| 水电 | 较高 | 强 | 5-10年 | 较低 |
| 核电 | 极高 | 低 | 5-10年 | 较低 |
| 风电 | 低 | 弱 | 1-2年 | 持续下降 |
| 光伏 | 低 | 弱 | 6-12个月 | 持续下降 |
| 储能 | 灵活 | 强 | 灵活 | 快速下降 |

## 四、电网体系

### 4.1 中国电网格局

- **国家电网**：覆盖26个省市自治区，服务人口超11亿
- **南方电网**：覆盖广东、广西、云南、贵州、海南
- **蒙西电网**（内蒙古西部）：独立运行，已并入国家电网管理体系
- **地方独立电网**：部分偏远地区或工业园区

### 4.2 电压等级体系

- **特高压（UHV）**：±800kV、±1100kV直流；1000kV交流，用于远距离输电
- **超高压**：500kV、330kV
- **高压**：220kV、110kV
- **中压**：35kV、10kV（配电）
- **低压**：380V/220V（用户端）

> 电压越高，传输损耗越小，但建设成本越高。

## 五、行业体制改革

### 5.1 主要历史节点

- **1985年前**：高度集中的计划经济，独家经营
- **1985年**：开始"集资办电"，鼓励多方投资发电
- **1996年**：成立国家电力公司，政企分开
- **2002年**：厂网分开，组建五大发电集团（华能、华电、大唐、国电、中电投）+两大电网
- **2015年**：新一轮电改启动（"9号文"），放开输配以外的竞争性环节
- **2021年起**：推动新能源为主体的新型电力系统建设

### 5.2 主要市场参与者

**中央电力企业（央企）**
- 发电：华能、华电、大唐、国电投、中广核、国家能源集团等
- 电网：国家电网、南方电网

**地方能源企业**
- 各类省属能源集团（如京能、申能、皖能等）

**民营/外资**
- 主要集中在新能源开发、售电、综合能源服务等竞争性环节

## 六、电力市场

### 6.1 中国电力市场结构

- **中长期市场**：年度、月度、双边协商交易（占大头）
- **现货市场**：日前、日内、实时市场（试点逐步扩大）
- **辅助服务市场**：调频、调峰、备用、黑启动等
- **绿电交易**：绿色电力证书交易（绿证）+绿电直接交易

### 6.2 电价体系

- **上网电价**：发电企业卖给电网的价格（部分已市场化）
- **输配电价**：政府核定的过网费
- **销售电价**：终端用户价格，分居民、农业、工商业
- **分时电价**：根据峰谷时段差别定价，引导削峰填谷

## 七、新型电力系统

### 7.1 核心特征

- **能源结构清洁化**：新能源逐步成为装机主体（2025年风光装机已超煤电）
- **系统形态去中心化**：分布式电源、储能、微网大量接入
- **运行特性复杂化**：源网荷储多向互动，电力电子设备占比上升
- **体制机制市场化**：价格机制、交易机制持续完善

### 7.2 关键挑战

- **新能源消纳**：风光发电的波动性如何与电力系统匹配
- **系统调节能力**：储能、灵活性电源、需求响应的发展
- **电网安全稳定**：高比例可再生能源下的电网运行新问题
- **投资与回报**：新能源大规模建设后的电价、补贴、市场机制问题

## 八、关键术语速查

| 术语 | 含义 |
|------|------|
| **装机容量** | 发电机组的额定功率，单位GW/MW/kW |
| **发电量** | 实际发出的电能，单位TWh/亿kWh |
| **利用小时数** | 发电量/装机容量，反映设备利用水平 |
| **峰谷差** | 最大负荷与最小负荷的差值 |
| **调峰** | 应对负荷波动的发电出力调整 |
| **备用容量** | 应对突发情况的额外装机冗余 |
| **度电成本（LCOE）** | 平准化度电成本，衡量电源经济性 |
| **消纳** | 新能源发电被电网吸收使用的能力 |
| **绿电/绿证** | 绿色电力的直接交易或凭证交易 |
| **虚拟电厂** | 通过软件聚合分布式资源参与电网调度 |
| **新型储能** | 抽水蓄能以外的储能（电化学、压缩空气等） |
| **特高压** | ±800kV及以上直流或1000kV交流输电 |

## 九、行业政策环境

### 9.1 主要政策方向

- **双碳目标**：2030年前碳达峰，2060年前碳中和（2020年提出）
- **能源安全**：能源饭碗必须端在自己手里
- **电力保供**：极端天气、新能源出力不足时的电力可靠供应
- **市场化改革**：建设统一电力市场体系
- **新质生产力**：与电力行业结合（绿电+算力、绿电+氢能等）

### 9.2 主要监管部门

- **国家能源局**：行业主管
- **国家发改委**：价格、规划、政策
- **国家电力监管机构**（原电监会职能并入能源局）
- **地方政府**：项目核准、电价管理等地方事权

## 十、分析行业的几个视角

进行电力行业研究和分析时，可以从以下几个维度切入：

1. **供需视角**：电力供需平衡、装机与用电增速匹配
2. **政策视角**：双碳目标、电力体制改革、新型电力系统建设
3. **技术视角**：新能源成本下降、储能技术、电网技术演进
4. **市场视角**：电价走势、市场化交易、跨省跨区送电
5. **投资视角**：央国企与民企的角色、不同环节的投资逻辑差异
6. **国际视角**：全球能源转型、中国电力装备出海、跨国电力合作

## 十一、容易混淆的概念

- **装机≠发电量**：装机是设备能力，发电量是实际产出（受利用小时数影响）
- **发电量≠用电量**：发电量包含厂用电、线损等
- **新能源≠清洁能源**：核能是清洁能源但不是新能源；天然气通常被分类为清洁能源
- **储能≠蓄能**：广义储能包括抽水蓄能、新型储能；狭义仅指新型储能
- **绿电≠绿证**：绿电是物理电量；绿证是绿色属性凭证，可单独交易
- **特高压≠超高压**：特高压指±800kV/1000kV等级，超高压是500kV/330kV
